# Sukoon

> **Building a stronger, more inclusive community for Muslim families with children who have special needs.**

Sukoon is an AI-powered platform that helps Muslim families of children with special needs connect with trusted caregivers, supportive communities, and authentic Islamic guidance. By bringing these resources together in one place, Sukoon aims to reduce isolation, foster meaningful relationships, and empower families with the support they need.

---

## Project Overview

Families raising children with special needs often face unique challenges, from finding experienced caregivers to connecting with other families who understand their experiences. Accessing reliable Islamic guidance tailored to disability-related questions can also be difficult.

Sukoon provides a centralized platform where users can:

- Connect with verified caregivers experienced in disability support and Islamic values
- Find local families from their mosque or community with similar experiences
- Join peer support circles focused on topics such as Ramadan, sensory-friendly prayer, and advocacy
- Access authentic scholarly guidance on disability accommodations in Islam
- Use the AI Scholar Companion to ask questions about parental concerns, fasting exemptions, prayer accommodations, and other related topics

---

## The Problem We're Solving

Families of children with special needs are often underserved and can struggle to find understanding communities, qualified caregivers, and trustworthy religious guidance that addresses their unique circumstances.

Sukoon was created to bridge this gap by providing a safe, accessible platform where families can build connections, share experiences, and access resources that help them navigate everyday challenges with confidence.

## How We Built It

Sukoon was developed using **Google AI Studio**, where we generated and refined the application's code while previewing changes in real time. The AI Scholar Companion is powered by the **Google Gemini API**, enabling intelligent and context-aware responses. **Firebase Authentication** and **Cloud Firestore** were used to securely manage user accounts and application data. The completed project is hosted on **Google AI Studio** and published to **GitHub**.

## Setup Instructions

To work with this project, you will need:

- A Google AI Studio account
- Access to the project's source code
- A Google Gemini API key
- A Firebase project configured with Authentication and Cloud Firestore

After cloning or downloading the repository:

1. Open the project in Google AI Studio.
2. Configure your Google Gemini API key.
3. Configure your Firebase project credentials.
4. Run the application using Google AI Studio.
